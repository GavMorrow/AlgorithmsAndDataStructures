# Places Database

**Note:** You can either choose "MinMaxPQ" or "PlacesDatabase"! You cannot choose both.

Implement 2 distinct approaches for a data type `PlacesDatabase` that can:

- Add places, where a place consists of an (x, y) coordinate pair.
- Return the closest place to a given x coordinate.
- Return the closest place to a given y coordinate.

You must use the Place object within your implementations.
